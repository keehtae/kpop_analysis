SM / JYP / YG shared cues

Editorial Scale. Minimal Color. Artist-First Storytelling.

This local site translates the visual language common to SM, JYP, and YG into a K-pop chart-analysis hub: restrained black-and-ivory color, large uppercase headlines, spacious grids, and a clean showcase layout where the content carries the page.

Chart analysis and music highlights use Artists/20w1_26w35_artists_cleaned.csv. Unique songs are counted by artist and title; song–artist–album combinations count album releases separately.
