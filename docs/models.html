This page is set up as the modeling layer for the project. It follows the same gallery-like rhythm as the label reference sites, but the content blocks are organized around forecasting, ranking, and survival-style questions you may want to test next.

Candidate Tracks

Three model directions

Longevity Model

Predict total weeks on chart from early-week rank behavior, agency, release timing, and score momentum.

Peak Rank Model

Estimate whether a track will enter the top 10, top 3, or #1 using first-entry conditions and artist history.

Volatility Model

Model week-to-week movement magnitude to learn which songs are stable climbers versus event-driven spikes.
